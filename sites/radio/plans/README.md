# Radio plans and proposal archive

**Status:** Historical and proposed material; not an approved current roadmap.

The files in this directory record ideas and plans from different points in time. They contain conflicting assumptions about product scope, geography, data sources, mapping/propagation technology, and implementation structure. Do not use an individual plan as proof that a feature is implemented or as an accepted requirement without confirming its status with the project owner.

Before implementation work based on these documents:

1. Confirm the desired user outcome and which proposal, if any, has been adopted.
2. Verify current code and infrastructure. `sites/radio` is not currently a complete runnable site workspace, and the Worker radio module's reachability must be checked in the main router.
3. Resolve data, migration, and deployment ownership before proposing operational changes.
4. Create/update a story and implementation plan using [the project templates](../../../docs/README.md#current-documentation).
