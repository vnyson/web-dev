# Architecture and product decisions

Use this directory for durable choices that affect multiple features or constrain future work—not for routine implementation notes or unapproved ideas.

When a decision is made, add `NNNN-short-title.md` with:

- **Status:** Proposed, Accepted, Rejected, Superseded
- **Date** and **decision owners**
- **Context:** the problem and relevant evidence
- **Decision:** the selected option and explicit scope
- **Alternatives considered** and why they were not selected
- **Consequences:** tradeoffs, migration/rollout needs, and follow-up work

Do not create speculative decisions merely to fill this directory. Link to accepted decisions from relevant architecture/workflow docs and update superseded records rather than deleting history.
